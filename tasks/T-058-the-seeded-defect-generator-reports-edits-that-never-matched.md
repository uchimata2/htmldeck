# T-058 — The seeded-defect generator reports edits that never matched

## 1. Specify

**Outcome**
[`tools/examples/seed_defects.py`](../tools/examples/seed_defects.py) cannot report a seed it did
not apply. Every edit asserts it matched, the way
[`static_variants.py`](../tools/deck/static_variants.py)'s `build` already does, and the S2
disclosure removal either matches or the run stops.

**Why this one**
The generator builds the blindness fixture — the deck used to prove that five of the ten evaluation
dimensions are invisible to any mechanical check (**L-05**, DS-190, DS-191). **A fixture that
over-reports its own coverage is the same defect one level up:** the claim *this deck carries a
seeded defect on every dimension* is what the fixture is for, and one seed has been counted without
being applied.

**What was found, 2026-08-09 by [T-016](T-016-the-interaction-and-motion-layer.md).** The S2 seed
*slide 7 assumption marker removed* is a `re.sub` whose lookahead expects the disclosure to sit
immediately before `<p class="provenance">`. The bottom line is between them, so it has never
matched — and the `applied.append(("S2", ...))` on the next line runs unconditionally, so the run
prints the seed as applied. The regenerated fixture is byte-identical to the committed one in that
region, which is how it was noticed at all: **T-016 widened the pattern to admit `data-disc="…"`
and the output did not change.**

**Scope**
- In: every seed in the file asserting that it matched, and failing the run when one does not.
- In: the S2 disclosure removal — repointed to what it means to remove, or dropped with a reason.
- Out: the *choice* of seeded defects and whether each is representative. That is
  [T-005](T-005-build-check-the-gate-the-deck-must-pass.md)'s and the rubric's.
- Out: the other three variant suites. `build` already asserts its anchors; this file is the one
  that does not.

**Inputs**
- [`tools/examples/seed_defects.py`](../tools/examples/seed_defects.py) — `sub()` asserts, the
  bare `re.sub` calls beside it do not.
- [`tools/deck/static_variants.py`](../tools/deck/static_variants.py) — `build`, which is the
  shape to copy: an anchor that does not match exits.
- [`docs/LESSONS.md`](../docs/LESSONS.md) — **L-04**, **L-36**.

**Acceptance criteria**
- [ ] Every seed asserts it matched; a seed that does not stops the run rather than reporting itself
- [ ] The S2 disclosure removal applies, or is removed with the reason recorded
- [ ] The dimension count the run prints is a count of edits that landed, not of edits attempted
- [ ] Regenerating the fixture from an unchanged reference deck is a no-op, so the committed
      artefact and the generator cannot drift silently

**Open questions**
- Should the fixture be regenerated by a check rather than by hand? It went stale once already —
  the committed copy predated `f65196a`'s easing change until T-016 regenerated it — which is the
  same class of drift. Whoever works this one.
