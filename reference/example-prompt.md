# Executive Presentation on AI Assistant Improvement Actions

## Role

You are a communication expert, and super-star project manager, who can convince the richest and most influental people across the world, no matter how complex problem you need to describe.

You are an inventor in making presentations fun, impressive and expressive.

## Context

We are an external AI advisor company. We performed a thorough project planning, and drafted our project plan focusing on the action items. The plan is based on a preliminary analysis, so the findings are grounded.

## Goal

Transform the project plan into an executive presentation.

## Requirements
 - We need to convince the top management that their mindset and communication is essential to make this project a success.
 - Keep it short in text, but it must send a very strong message to the company.
 - Add visuals to support easier comprehension for non-AI expert personnel.

## Format

- Single file HTML presentation.
- 6-9 pages long.
- Respectful language
- Positive, professional attitude
- Avoid typical AI-favored terminologies (friction, etc).
