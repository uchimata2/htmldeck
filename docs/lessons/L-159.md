# L-159 — A finding that names its own test can still have been counted by a coarser one, and then its number is an over-count nobody re-derives

Found 2026-09-02 in [T-293](../../tasks/T-293-the-second-runs-low-findings-in-one-pass.md), closing
`CE-20`. The finding read *five memory-index entries duplicate a rule that has a home*, worth about
930 bytes on every turn, and it named the test to apply: the *memory with a repository home is spent*
entry. That entry's test is **per facet** — an entry is spent when *every* facet of it is superseded
or absorbed, and a cross-project facet is neither. Applied as written, the five are **two**, worth
219 bytes. One of the three kept is named as a keeper, by id, inside the very entry the finding cited
as its test.

- **Naming a test is not applying one.** *Duplicates a rule that has a home* and *has no facet that
  lacks a home* are different questions with the same answer most of the time, which is what makes
  the gap survive review. The finding was counted by the first and stated the second.
- **An over-count is quieter than an under-count.** [L-156](L-156.md) is the other direction, found
  the same day: a reported instance was four, and a reported two were 44. Those get discovered when
  the fix runs out of subjects. An over-count is discovered only if somebody re-derives the number
  before acting on it — and the closing session is under pressure to hit the figure, so the failure
  mode is deleting three things that should have been kept.
- **The damage is asymmetric and the cheap direction is obvious.** Under-counting costs another pass;
  over-counting costs a fact its only home, and a memory entry moved out on a wrong reading is not
  recoverable from the repository, because the repository is exactly where it was not.
- **So re-derive a finding's count with the finding's own stated test before acting on it**, and
  record what the test returned beside what the finding claimed. Both numbers, on the row. The band
  is part of the finding and it is graded like the rest of it.
