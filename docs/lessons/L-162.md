# L-162 — A note saying nothing uses a rule yet is falsified by the rule working, and no gate reads a comment

Found 2026-09-02 in cycle 41 of
[T-219](../../tasks/T-219-pre-release-audit-of-the-whole-repository.md), the pre-release audit's
re-read of what its own remedies changed.

[`tools/docs/cycles.py`](../../tools/docs/cycles.py) assigns every tracked path to exactly one audit
cycle. Cycle 7's rule includes *every `shipped_in: unreleased` record*, and the comment beside it
explained why the rule existed before anything matched it: **no record carries the value today; the
first one to close after `0.6.0` will, which is why the rule is here before it is needed.** That was
exact when written. The remediation then closed 68 tasks, every one of them `unreleased`, and the
rule went from matching nothing to supplying most of cycle 7's files.

**The sentence saying the rule had no subject was falsified by the rule acquiring one** - the very
outcome it predicted and was written to prepare for.

- **The falsifier is the success, which is why nobody goes back to check.** A note justifying work
  done ahead of need is a claim about the present, and the point of working ahead is that the present
  will change. Every other stale figure has a neutral cause - something grew, something moved. This
  one has a cause the author was hoping for, so the moment it goes false is the moment everybody is
  pleased.
- **Present tense with no date is what makes it unrecoverable.** *Today* cannot be checked: a reader
  four months later cannot tell whether the claim was taken this morning or before the work that
  falsified it. A date turns a false statement into a true dated one at no cost, which is
  [L-95](L-95.md)'s move applied to a claim rather than to a figure.
- **No gate reads a comment.** [`tools/docs/figures.py`](../../tools/docs/figures.py) binds pasted
  output and prose numerals inside *documents*; a Python comment is neither, and `refcheck.py`
  resolves pointers rather than claims. So this class has no instrument at all - it is found by a
  person re-reading, which is exactly what cycle 41 is.

**How to apply.** When you write a rule, a fixture or a branch before it has a subject, **date the
sentence that says so**, and prefer *what answers it* to the answer: `python tools/docs/cycles.py
--cycle 7` counts the matches and cannot go stale, where *no record carries the value* can and did.
The milder relatives are [L-52](L-52.md), where a pasted figure decays because its subject grew, and
[L-152](L-152.md), where a total decays because an item was added; this is the case where the claim
is about **absence**, and absence is the one state that ends the instant the design works.
