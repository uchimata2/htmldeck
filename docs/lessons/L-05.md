# L-05 — Say which half you checked

A check that *looks* complete is worse than no check, because a partial pass gets read as a
verdict on the whole.

**How to apply.** State in the output what was **not** examined. `task.py check` reporting "0
broken links" was true and misleading in the same breath: it validated links between task files
while two documents the tooling itself pointed at did not exist. Name the scope in the success
line, not only in the failure.

**The mirror case, and it has now happened twice in three releases.** `figures.py` cites this lesson
in its own success line — *it cannot tell you the sentence around a figure is still true* — and both
times the release sequence's step 4 was the only thing that caught it. `v0.1.4` found a spelled-out
fixture count and a defect tally that had both gone false. `0.3.1` found `README.md` naming one of
PH2's two trailing tasks as still open, four days after
[T-036](../../tasks/T-036-the-second-contents-page-for-long-decks.md) closed and shipped in `0.3.0`.
Every pasted figure on the page was correct on both occasions.

**Both instances share a shape, which is what makes an instrument thinkable**: prose asserting a
state — *still open*, *all three are fixed*, *two of them* — about something the repository already
tracks the state of. That is a narrower target than "read the prose", and it is the difference
between a lesson and a check. Nothing is built yet, and until something is, **step 4 is a person and
the release sequence says so**.

**A third instance, `0.7.0` on 2026-09-03, and it splits the shape in two.** One half is the one
above: the front page said *twenty-four of the fixes* two paragraphs under its own *eighteen tasks
raised*, so the page contradicted itself about a count the same page states. **The other half is new
and is not drift at all** — the page said the frame-rate figure and the glitch-free conditions *were
listed here too, until this release*, which was true until step 2 bumped the version and false the
instant it did. **The release sequence falsifies that sentence itself.** Prose whose referent is
*this release* has no stable meaning across a bump, and nothing about the sentence changes when it
goes false, so no diff shows it.

That is a narrower target again, and a cheaper one: a phrase naming **the current release**
indirectly — *this release*, *the current one*, *until now* — in a document that also carries the
version string. Both instances were found by step 4 and by nothing else, which is now three releases
running.
