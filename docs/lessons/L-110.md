# L-110 — An interactive control cannot be looked at in a snapshot, and the snapshot reports zero rather than failing

Caught 2026-08-17 (**T-168**). The task needed one thing to close: open the sources box and look at
it. The session that raised it had a preview that renders the deck as a **static snapshot** — the
DOM is painted, no page script runs. So the click did nothing, the box stayed shut, and the row's
height came back as **0**. The task was parked overnight as *needs a person and a browser*, which
was the right call on a wrong diagnosis: the browser was the missing half, not the person.

Opened the next day in a pane that runs the script, the same control flips `aria-expanded` and lays
out at **52 px**. Nothing about the deck had changed.

**The tell is the shape of the wrong answer.** A snapshot does not refuse an interaction, and it does
not report that it declined one. It returns the measurement of a thing that never opened — `0`, or a
`getBoundingClientRect()` of all zeroes — which reads exactly like a real measurement of a broken
control. The instrument's limit arrives disguised as the deck's defect.

**How to apply.**

1. **Before measuring anything behind an interaction, prove the script runs.** One assertion is
   enough and it costs a line: toggle the control and read the state attribute back. If
   `aria-expanded` does not move, stop — nothing measured after that point is about the deck.
2. **Treat a zero from an interactive measurement as the instrument's answer until proven
   otherwise.** A closed element and an absent element measure the same, and so does an element in a
   page whose script never ran. Three causes, one number.
3. **`CLAUDE.md` rule 6's *open it* is a requirement on the instrument, not only on the person.**
   Rule 6 rules out reading the HTML and rules out a green gate; this adds the case it did not
   name — a render that cannot be operated is not a look either, however faithfully it paints.

**What this cost and what it bought.** One overnight park, and a task held at `review` for a reason
that had already stopped being true. What it bought is larger: the same live pane, in the same
sitting, exposed [**T-174**](../../tasks/T-174-the-quick-view-reopens-at-the-previous-documents-scroll-offset.md)
— a stale scroll offset that exists only in the **second** opening of a control, which no snapshot
could ever have shown and no gate here looks for. The instrument that can operate the deck is the
one that finds the defects living in interaction, and this repository ships a deck whose whole tier-2
argument is interactive.
