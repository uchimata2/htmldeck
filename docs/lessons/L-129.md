# L-129 — A check for something the corpus does not contain is never seen to pass, and that looks exactly like working

**L-36** says a check that has never been seen to fail is a claim about the instrument. This is the
same statement with the sign flipped, and it is harder to notice because the instrument stays quiet
in the direction that would give it away.

Write a check whose subject no artefact in the repository has. Every deck reports *no subject*, and
that is the correct answer — the rows are honest, the account is honest, and nothing anywhere is
wrong. Then seed a broken instance and watch the check catch it. Now the check has been seen to
fail, which is the bar **L-36** sets, and the suite says so in a number.

**None of that establishes that the check can say yes.** A scan that returned *blank* for every
input, or a predicate hard-wired to `False`, produces exactly this record: correct declines on the
real corpus, a caught variant, a green suite. The one state that would expose it — a real subject
the check must accept — is the one state the corpus cannot produce.

Measured 2026-08-22. R6's condition 7 asks that every canvas surface drew something, tested by
reading pixels back and looking for ink. No deck in this repository draws a canvas, so the
condition returned NO SUBJECT on all four, and the seeded variant — a canvas that draws nothing —
came back caught. Seven of seven variants caught, gate green. The pixel scan had never once been
handed a surface with ink on it.

**How to apply.**

1. **Ask which states a check has actually been observed in, not how many variants caught it.** The
   count is over seeds, and every seed in a *must fail* suite exercises one direction.
2. **Where the corpus cannot produce the subject, seed the subject rather than waiting for one.**
   The seed that proves the pass is a different artefact from the seed that proves the fail, and a
   suite shaped only to break things has no place to put it.
3. **Assert the state, not the absence of the other one.** *Not among the failures* is satisfied by
   NO SUBJECT, which is what the unbroken corpus already reports — so the assertion passes without
   the seed ever being seen. Require the row to come back `True`.
4. **Treat a permanently subjectless check as unfinished, not as covered.** It is a check whose
   whole behaviour on real input is one branch, and the account will keep reporting that branch
   accurately for as long as nobody looks.

The general shape: **a check has as many directions as it has verdicts, and a corpus proves only the
ones it contains an instance of.** Related: **L-36** and **L-42** for the failing direction,
**L-57** for the absent-subject family this sits inside, and **L-04**, which is the same
both-directions bar one level down.
