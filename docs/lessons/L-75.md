# L-75 — A guarantee is only as wide as the population it was checked against

Caught 2026-08-13, twice in one task (**T-107**, **T-122**). **L-04** makes a tool refuse to report
when its own self-test fails, and this project reads that as a guarantee. It is not one on its own:
it is a guarantee about the fixtures, and the fixtures are somebody's memory of the input.

Two shapes of the same failure, both in the quick view, both live in a published release:

- **The self-test was narrower than the input.** `markdown()` had fixtures for headings, bold, code,
  lists and tables — a fair description of what its author had in mind. A thematic break was in
  **119 of the 355 source documents in the corpus** and in no fixture, so the renderer shipped `---`
  as a paragraph of hyphens and every run was green. Counting the corpus also found two more gaps
  nobody had reported and settled an ambiguity the fix would otherwise have argued about.
- **The check was narrower than the contract.** `COMPONENT-CONTRACT.md` has an `origin` column, and
  a row saying `.qv-doc` is an `<article>` the **script** creates. The placement check reads the
  deck's static markup, so it can only see what the *build* writes; it reported `0 problem(s)` while
  the element did not exist in any deck and seventeen rules written against it matched nothing. The
  document named the category the instrument cannot see, in its own schema, and no check read that
  column.

**How to apply.**

1. **Name the population before the fixtures.** Count what the real input contains — the corpus, the
   contract's own rows — and derive the cases from that. A fixture list built from what came to mind
   measures the author, not the input.
2. **Put the count in the failure message.** *"dropped a thematic break, in 119 of 355 corpus
   documents"* tells the next reader why the case is there; *"dropped `<hr>`"* invites deleting it.
3. **Read the schema for what the instrument cannot reach.** A contract with an `origin`, a `kind`
   or a `when` column has already sorted its rows into what a static check can see and what it
   cannot. Any value in that column with no instrument behind it is an unkept promise.
4. **A green run over an unnamed population is not evidence.** It is the same claim as a check that
   has never been seen to fail (**L-36**), one level up: the check ran, and nobody said over what.
