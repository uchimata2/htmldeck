# L-97 — A check anchored on the value that drifts goes blind exactly when it is needed

Found 2026-08-14 by
[T-154](../../tasks/T-154-bind-the-measurements-that-five-live-documents-state-in-prose.md).
[`figures.py`](../../tools/docs/figures.py) watches whether a document's prose still matches the
command that produced it. Four documents — the specification, the scoring contract, the public
worked example and the shipped skill — said *"82 of the 113 rules a gate owns"* while the gate
printed **84 of 115**, and the tool reported `0 stale figure(s)`.

**It was not checking the sentence shallowly. It was not checking it at all.** The claim was found by
asking which of the command's fields carried the *whole* as its value. Nothing prints `113` any more,
so the sentence matched no field, and it fell into the bucket of numerals the tool declines to judge —
alongside 420 that are not figures in the first place. **The moment the account moved, every page
still quoting the old number stopped being watched, because it was wrong.**

**It is the missing half of [L-63](L-63.md)**, which recorded that binding on the claim's
*construction* beat binding on its vocabulary — thirty false alarms against five true ones. That was
right, and it said nothing about what locates the construction. Here the shape was found by matching
the whole against the printed values, so the anchor was the number that moves.

**This is a fixture rule applied one scope out.** The same file's self-test already carries it:
*a fixture may assert what the page's wording binds; it may not require the page to be right first*
(**L-78**, T-127). That was written after a fixture built its seed by string-replacing the page's
correct sentence, so on the one day the page had drifted the seed was empty and the fixture reported
the tool broken instead of the page. The production path had the identical substitution and nobody
looked, because a check that is silent and a check that is passing print the same thing.

**How to apply.**

1. **Ask what the binding survives.** For each thing a check identifies its subject by, ask what
   happens when *that* thing is the thing that went wrong. If the answer is "the check finds
   nothing", the check is anchored on its own failure condition.
2. **Anchor on what does not move.** Bind by the sentence's shape, by a link, by a declared name —
   then compare the value. The value is the verdict, never the way in.
3. **A silent bucket is a claim about the check, not about the corpus.** `unanchored 421` looked like
   a documented remainder for a year. Anything that leaves the watched set for a reason the tool does
   not report can leave it because it broke.
4. **Count the shape's alarms before trusting the vocabulary argument against it.** The rival here
   was a classifier over 434 numerals whose *other* bucket nobody could verify. The shape fires 8
   times in six documents and 4 of them are the defect — auditable by reading eight lines, which is
   the property that decided it.
