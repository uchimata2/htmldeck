# L-151 — A prohibition that spells the token it forbids is destroyed by whatever substitutes it

Found 2026-08-30 in [T-227](../../tasks/T-227-the-front-pages-adoption-route-names-a-variable-the-skill-removed.md),
while measuring something else. `SKILL.md` section 0 carried a paragraph telling an adopting agent
not to write Claude Code's plugin-root placeholder into a shell command, and it made the point the
way prose makes points — by quoting the thing:

> **Do not write `<placeholder>` in a command.** … `python <placeholder>/tools/deck/check.py`
> becomes `python /tools/deck/check.py`.

**Claude Code substitutes that placeholder into the skill body before the agent reads it.** So the
paragraph never arrives. What arrives forbids a version-pinned absolute cache path, twice, in bold,
and then asserts that a correct absolute path *becomes* a command rooted at the drive — which is
false. A paragraph written to stop [T-189](../../tasks/T-189-resolve-the-plugin-root-in-every-documented-command.md)'s
87 hardcoded version-pinned paths was, as delivered, the single most prominent version-pinned path
in the skill.

- **A document that is processed before it is read cannot quote its own machinery.** The rule and
  the mechanism the rule is about live in the same namespace, and the mechanism wins. This is not
  specific to one placeholder: any template variable, any macro, any `{{…}}` a renderer expands is
  a token a prohibition cannot name.
- **The failure is silent and it inverts the meaning.** Nothing errored. The sentence stayed
  grammatical, stayed emphatic, and taught the opposite of what it said — which is worse than a
  paragraph that had simply gone missing, because a missing one gets noticed.
- **No gate here could see it.** `check_scaffold.py` reads the file from disk, where the token is
  intact and correct. The defect exists only in the delivered copy, and the only instrument that
  reads that copy is the agent the document is addressed to. **It shipped in `0.6.0`.**

**What to do with it.** State the rule without spelling the token — describe the variable rather
than write it, and let the reason carry the weight. Section 0 now says *never write a plugin-root
placeholder into a command*, notes that the harness substitutes its own before you read this, and
explains why the paragraph therefore does not spell it out. The lost concreteness is worth the
sentence surviving delivery.

**And the general form is worth more than the instance.** A document read through a processor is
not the document on disk, and every claim it makes about the processor is evaluated by the
processor. Before writing about a mechanism, ask what that mechanism does to the sentence — and
where possible, **read the delivered copy rather than the source**. Loading this skill once, and
reading what actually arrived, is what found this; reading the file never would have.
