# L-124 — Seed the form the artifact contains, not the form you typed

Found 2026-08-20 (**T-201**), hours after **T-197**'s rule shipped in `0.5.0`. Four checks written
in one day found nothing on their first run. Three were caught before release; the fourth was not,
and the difference is one word: **seeded**.

**The one that shipped.** DS-241 forbids an eyebrow that repeats the slide's position and stage. Its
check flattens the eyebrow to text and looks for a digit followed by a separator. The deck it was
written from reads `07 &middot; Structure`, and the flattening decodes `&nbsp;` and `&amp;` and
nothing else — so the check saw a digit followed by an **ampersand**, and passed. It reported **`0`
offending eyebrows on a deck where all fifteen were the defect**, and passed the whole gate.

The three decks in this repository were clean, which is what made the green believable. They were
clean because they had been re-cut by hand an hour earlier, not because anything had been seen to
catch anything.

**Why the seeded checks survived and this one did not.** The other three were tried against a
deliberately broken copy before the green was believed, exactly as **L-04** requires, and all three
turned out to be wrong:

- one matched hover and press rules by base *string*, and the defect it existed for is a *subset*
  relation — the two rules never share a base, which is the mechanism of the fault itself;
- the same check then found nothing for a second reason: the house pattern that splits CSS reads the
  comment above a rule as part of its selector, and nearly every rule here is commented;
- a fixture asserted on `FAIL     DS-140` where the row prints `FAIL  DS-140`, so the assertion could
  not fail at all.

Each was caught in seconds by putting the defect back. DS-241's was never put back.

**The rule.** L-04 says verify the checker on a known case. This is the clause it does not state:
**the known case has to be the form the artifact actually contains.** A generator writes
`&middot;`, `&nbsp;`, `&#8212;`, a normalised path, a minified attribute order; a person writing a
fixture types the character. Both are the same defect to a reader and different strings to a regex,
so a fixture built from what you typed measures the check against a document nobody produced.

**How to apply.** When seeding a defect, take the string out of a real artifact rather than writing
it — copy it from the file the rule was reported against. Where a value has an escaped and an
unescaped form, seed **both**, and say in the fixture why there are two. A check that catches only
the typed form catches only decks nobody built.

**And the thing that found it was a look.** The gate said the deck was clean; rendering one slide
and reading the top strip said otherwise (`CLAUDE.md` rule 6). No instrument in this repository
would have closed the gap, which is the same finding **L-05** keeps making from a different angle.
