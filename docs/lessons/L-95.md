# L-95 — Write the decision a figure drives, and let the command print the figure

Found 2026-08-14 by [T-148](../../tasks/T-148-give-a-measured-figure-a-durable-home.md), working
`CE-08` — *a measured figure gets a durable home*. The instance was the release gate's run time:
**five successive handoffs carried "the release gate takes 7–11 minutes" and the real figure was 154
seconds.** No committed document was wrong, because no committed document stated it at all.

The obvious remedy is to write the number down where a gate can check it. That does not work here,
and the reason generalises. **A run time is a property of a machine on a day**, not of the
repository: bound as a checked figure it would fail the gate for load, and written as prose it goes
stale exactly as [`L-94`](L-94.md) point 4 says — self-measurement is not self-updating, and the
figure is only ever as fresh as the last person who ran the command.

**What made the figure worth carrying was never its value.** Every session that repeated it was
answering one question: *do I run this in the foreground or the background?* That decision does not
move between 154 seconds and 164; it moves between seconds and minutes. **The decision is coarser
than the figure**, and the coarse fact is the durable one.

**How to apply.**

1. **Ask what the figure decides.** If nothing acts differently at different values, it is not owed a
   home at all — it is an observation, and a dated record is enough.
2. **Where the decision is coarser than the figure, write the decision and print the figure.** Here:
   `PUBLISHING.md` §8 says the gate takes minutes and must be backgrounded, and `check_all.py` prints
   its own elapsed seconds on every run. **No document states a number, so no document can hold a
   stale one.** This is the rule [`CLAUDE.md`](../../CLAUDE.md) already applies to the tier-1 bound —
   *no constant is written anywhere* — stated once instead of per instance.
3. **Where the decision needs the value itself, bind it** to the command that produces it with
   `tools/docs/figures.py`, and declare it a `floor` if it counts the repository rather than a
   decision — it may then be exceeded without reddening, and a stated zero stays exact. That tool's
   own two-kinds-of-number rule is the test.
4. **A dated record is not a stated figure.** *Measured 164 s on 2026-08-14* in a task log or a
   byproduct register is history and stays true; *the gate takes 164 s* in a live document is a claim
   that decays. The same distinction `figures.py` draws when it skips a struck-through done row.
5. **The tell:** a number that keeps arriving in handoffs, chat and summaries while no committed file
   contains it. It is being carried because it is needed and nothing owns it, which is the state where
   it is free to drift — and it drifted by a factor of four before anything caught it.
