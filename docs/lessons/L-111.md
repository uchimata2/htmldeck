# L-111 — A sanitization scan must walk every file type, because the one nobody reads is the one nobody sanitized

Caught 2026-08-17 (**T-128**), on the last check before a deck copied in from another project was
published. The sanitization was done, measured and recorded: 167 substitutions across 14 files, and
a re-scan reporting **0** for the case company in every class. Re-running the scan at close, over
**every** file rather than over the ones a person reads, returned the case company's name still
present — twice, as `targetNamespace="http://<case-company>/bpmn"` in the two BPMN models.

**The earlier pass was not careless; it was scoped to rendered text and Markdown.** That covers the
deck, both specifications and all five source documents. It does not cover an XML attribute in a
model file, and an attribute is exactly where a name survives an editorial pass: nobody proof-reads
a namespace URI, it renders nowhere, and no gate in this repository has an opinion about it.

**The tell is a file type with no reader.** A `.bpmn`, a `.yaml` sidecar, an `.svg`'s `id`
attributes, a font's metadata, an EXIF block. If the sanitization was done by reading, the classes
it removed are still present wherever reading does not go.

**How to apply.**

1. **Walk the tree, not the document set.** `rglob("*")`, every file, decode what decodes, skip what
   does not. Naming the file types to scan reproduces the same blind spot one level up.
2. **Print the match and its context, never a count.** The 2026-08-13 survey on this same task got
   165 training-context hits of which 148 were the word *example*; the answer was to show each hit,
   not to tune the pattern blind. A scan reporting `0` is only as good as what it looked at, and a
   scan reporting `4` with four lines of context can be judged in seconds.
3. **Re-run it at close, not only after the edit.** This class had been believed clear for a day
   across three sessions. The criterion said *checked by re-running the scan rather than by reading*
   and that wording is what caught it — the check was cheap, and the thing it protects is
   irreversible once pushed.

**What it would have cost.** A public repository, a public commit, and a name that
[`docs/PUBLISHING.md`](../PUBLISHING.md) exists to keep out of one — recoverable only by the history
rewrite that CLAUDE.md says is no longer available now that the history is public. Related:
[L-110](L-110.md), the same shape one instrument over — a check that answers honestly about the part
it looked at.
