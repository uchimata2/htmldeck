# L-120 — A centred viewBox inserts a margin nobody authored, and it looks exactly like one that was

An `<svg>` sized by CSS and given a `viewBox` has two independent alignments, and only one of them is
visible in the markup. The drawing's own coordinates are the one an author edits. The other is
`preserveAspectRatio`, which defaults to `xMidYMid meet` — so whenever the element's box and the
viewBox disagree in proportion, the browser fits by the constraining axis and **centres the slack**.
The drawing arrives inset, and nothing in the file says so.

Measured 2026-08-19 across three shipped decks, 21 diagrams, against a rule requiring each one's ink
to start on the slide's text column:

| Cause | Diagrams | Range |
| :--- | :---: | :--- |
| aspect letterbox, nobody chose it | 9 | 1.3 – 140.2 du |
| the drawing's own left margin | 12 | 2.2 – 121.0 du |
| **off the column** | **18 of 21** | up to 217.9 du |

Six carried both. **The two are indistinguishable in the rendered result and need different fixes** —
`preserveAspectRatio="xMinYMid meet"` for the first, a `viewBox` `min-x` for the second. Correcting a
letterbox by shifting `min-x` measures clean and is still wrong: it pushes ink outside the viewBox
rectangle, and it leaves a number that means *half this wrapper's aspect slack today* in the place
where the next author will read *where the drawing starts*. The wrapper's height is a layout outcome,
so that number is invalidated by an edit to the slide above it.

**Why it survives review.** A centred diagram looks deliberate. It is the arrangement a designer
would choose, so nobody reads it as a fault, and the fault only becomes visible when a row of text
sits directly under the figure — at which point it reads as a step rather than as a margin. Three
decks shipped through a 114-rule gate with 18 of 21 diagrams off the grid.

**How to apply.**

1. **Split the measurement before fixing anything.** The offset a probe reports is a sum. Read where
   the viewBox's own left edge lands — `getScreenCTM()` plus the `viewBox` origin — and subtract: what
   remains on one side is the letterbox, on the other the author's margin.
2. **Write the alignment keyword everywhere, not only where slack is measured today.** A diagram with
   no letterbox now grows one the moment the content above it reflows.
3. **Compute the coordinate fix from the rendered page, never from the markup.** The scale factor
   between viewBox units and design units is a layout outcome; a shift derived from the source is a
   shift in the wrong units.

The general shape: **a default that centres is a decision the file does not record.** Related:
**L-76** — a fault that lives only in one rendering mode — and **L-36**, since a rule that measures
the sum of two causes reports a number nobody can act on.
