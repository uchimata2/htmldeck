# L-121 — "Matches X exactly" holds only where the two are declared together

A component written to match another — same font, same tracking, same case — matches it in the file
where both rules are written, and nowhere else. Any consumer that restyles the original by name
leaves the imitator behind, silently, because the imitator was never in that selector.

Measured 2026-08-19. A shell defined `.decision-branch` to be `.lab` "in every respect", and it was:
both took `font-size: var(--fs-mono)`. A deck's own style block then stepped `.lab` up a size, with
the reason in a comment — at `--fs-mono` a figure label renders under the 16-unit floor once an
SVG viewBox scales it down. `.decision-branch` was not named in that rule, so it stayed at
`--fs-mono` and rendered **15.0 design units** beside edge labels the same deck had deliberately
enlarged.

**The gate saw it on one diagram out of two, and the difference was arithmetic nobody chose.** The
same class on the same deck rendered at 19.4 du on one slide and 15.0 on another, because one
diagram's viewBox scales *up* (×1.08) and the other's *down* (×0.83). The rule with the floor was
working perfectly; whether it fired depended on which slide the class happened to be used on. The
class's first use had been on the up-scaled one, which is why it shipped.

**How to apply.**

1. **A claim that two things match is a claim about a selector, not about two rule bodies.** If they
   must move together, put them in one selector — `.a, .b { … }` — so a later edit cannot reach one
   without the other.
2. **Where they cannot share a selector** — the base is shell and the override is per-consumer — say
   so where the override is written, not only where the class is defined. The consumer is the file
   that will break the pairing.
3. **A threshold rule crossed by a scale factor fires per instance, not per class.** Treat one green
   instance as evidence about that instance. Ask what the *range* of the scale factor is before
   reading a pass as coverage.

The general shape: **duplication that agrees today is not a shared definition, and nothing tells you
the day it stops agreeing.** Related: **L-13** — point at the source rather than restating it — and
**L-08**, the same failure one scope out, where two descriptions of one composition disagreed the
first time either changed.
