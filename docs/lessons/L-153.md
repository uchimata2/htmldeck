# L-153 — Output an agent captures is paid on every later turn, so a green run prints its verdict and the account prints on a terminal or on failure

Found 2026-09-02 in [T-286](../../tasks/T-286-print-the-verdict-on-a-green-run-and-the-report-only-when-asked.md),
from the owner's question after B17 about token consumption that grows with every turn. Measured on
that batch's green runs: `check_all.py` printed 18,480 bytes, `figures.py` 3,043, `lint.py` 2,222
and `chronology.py` 611, and each verdict was one line of it. A three-task batch ran the first four
times and the second about eight, and a session that captures a tool's output carries it forward on
every turn after the one that read it — so a green account nobody acted on cost about 25,000 tokens
of every later request in the batch.

- **A report is read once by a person and forever by an agent.** At a terminal the account scrolls
  away; in a captured stream it is context from then on. The same bytes have two prices, and the
  tool can tell which it is being paid: `isatty` is the whole test, so nobody has to remember a
  flag, and a person watching loses nothing.
- **Quiet decides how a green run reads and nothing else.** A red run prints everything, in every
  mode, and the self-test asserts that with a seeded failure rather than trusting it — a quiet mode
  that swallowed a failure is the one outcome worse than the report. Buffer the account and decide
  after the verdict is known; a tool that decides before it runs cannot make that promise.
- **The one line carries the partition's counts**, not the word *pass*. **L-05**'s *say which half
  you checked* is why the closing paragraphs existed, and the counts are that sentence in numbers:
  *7 ran, 35 skipped with a reason, 0 failed* says what *OK* cannot.
- **A flag restores the account, and one that nobody passes saves nothing.** `--report` for the
  person piping to a file, `--quiet` for the person at a terminal who wants the line; the default
  does the work, because the cost falls on the reader who is not there to choose.
