# L-161 — A derived figure written into a document that is inside its own subject cannot converge, and the case that converges by accident is the dangerous one

Found 2026-09-02 in [T-239](../../tasks/T-239-the-audits-own-record-against-what-it-did.md), closing
`PR-101`. The pre-release audit's cycle programme carried a `Bytes` cell per cycle, marked *printed,
not typed*. Cycle 7's subject is *the unreleased work, and this audit's own record* — which contains
the file holding the table. So writing that cycle's byte count into the table changes that cycle's
byte count: `1,250,171` replacing `132,120` is two characters wider, and the figure is wrong before
the editor closes. **The row had been wrong for months and no amount of care could have fixed it.**

- **The test is containment, not arithmetic.** Ask whether the document you are writing the figure
  into is part of what the figure measures. A repository size written into a tracked file, a line
  count written into the file counted, a task record stating the byte total of a set it belongs to —
  all the same shape. It is invisible in the prose, because a derived value reads as a description
  either way ([L-152](L-152.md) is the milder version, where the copy merely decays).
- **Width-stable substitution hides it, and that is worse than failing.** [`CLAUDE.md`](../../CLAUDE.md)
  states its own size against the smallest document it defers to. The same session re-measured both
  terms, wrote `15,833` over `15,742` and `7,996` over `7,905`, and the file landed at exactly the
  size it now claims. **That converged because two five- and six-digit numbers happened to have the
  same width**, not because the document is sound. Cross a power of ten, or add a word, and it
  silently stops converging with nothing to announce it.
- **So a gate over such a figure is a gate that can never go green.** The remedy `PR-101` offered —
  make the comparison a command, `cycles.py --plan --check` — was refused for this reason and not on
  cost: it would have failed forever on cycle 7 while every other row passed, which trains a reader
  to ignore it. A fence is only worth building where the fenced value is attainable.
- **The fix is to stop storing it.** Both columns were deleted and the table now points at
  `python tools/docs/cycles.py --plan`. That is [L-74](L-74.md) taken one step further: a derived copy
  that fails loudly beats one nobody diffs, and **no copy at all** beats both where the copy is
  unattainable. Where the figure genuinely must be stated in its own subject — `CLAUDE.md`'s bound is
  the case, because a claim about this file cannot be corrected anywhere else — say in the document
  that it is self-referential, and re-measure after writing rather than before.
