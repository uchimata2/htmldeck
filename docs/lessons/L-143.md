# L-143 — A guard added to narrow a rule can silence it, and the number that catches that is the rule's own prior count

Narrowing a check is the safe-feeling kind of change: it only ever removes findings, so the worst
case looks like *slightly fewer*. The worst case is actually *none at all*, and it arrives looking
exactly like a clean run.

Found 2026-08-29 closing [T-260](../../tasks/T-260-ds-244-tests-proximity-where-it-means-obstruction.md).
DS-244 was pairing two diagram labels at one point without reading whether either was visible, so a
cross-fade in place — the ordinary way to animate a value changing — read as a collision. The fix is
one line of intent: skip a label the reader cannot see. The first form of it read `visibility`
absolutely. **`visibility` is inherited, and in this deck every off-screen slide is
`visibility:hidden`**, so every label on eleven slides of twelve was invisible. The run came back
with **129 hidden labels** and every other count at zero.

Zero is the tell, and only if you know what the number was before. The verdict itself was green,
the deck was fine, and the new behaviour worked perfectly on the one fixture written for it.

**How to apply.**

1. **Before narrowing a check, write down what it currently counts** — not whether it passes. A
   boolean cannot show you a guard that swallowed everything; a count can.
2. **Re-run the calibration the rule already has.** Most rules worth narrowing were calibrated once,
   and that figure is a regression test nobody labelled as one. Here it was fifteen label-on-line
   placements; the guard took it to zero.
3. **Suspect every inherited property read absolutely.** `visibility`, `color`, `font-size`,
   `direction`: the computed value on a child says what the *page* did, not what the *element*
   asked for. Measure it against the frame the rule is about — here, against the slide.
4. **Ask what the environment does with the same mechanism.** A deck hides slides with
   `visibility`; an app hides routes with `display`; a table hides columns with both. A guard that
   uses the environment's own hiding mechanism is measuring the environment.
5. **A fixture that passes proves the new path, never the old one.** Both directions means the case
   you added *and* the cases you did not think about, which is what the prior count stands in for
   ([L-125](L-125.md)).
