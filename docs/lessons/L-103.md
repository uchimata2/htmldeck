# L-103 — A check with no negative case in its fixture is unproven where it matters

Met 2026-08-15 (**T-161**). A throwaway scanner was written to answer one question — how many table
rows in this repository carry more cells than their header — and a specimen file was written first,
outside the repository, carrying one instance of each property the scanner had to see. That is the
right instinct and it is what an upstream project had just recommended: *prove the scanner before you
believe its zeros*.

**The specimen passed while the scanner was scoring 3,150 false positives.** It had two checks. It had
a **positive** case for both and a **negative** case for only one, so the second check was never tested
in the direction it was actually wrong in. It fired when it should, so the fixture went green, and it
also fired on every table row in the tree that contained a code span at all.

Two more false positives followed the same way — YAML front matter read as a table row, which reported
the shipped task template as the only defect in the tree, and a run of three backticks in prose read as
an open span. **All three were caught by reading the hits, not by the fixture.**

**Zeros and non-zeros need opposite fixtures, and only one of them is habitual.** A fixture is built by
asking *would it notice*, so it fills with positives. Nothing in that process asks *would it stay
quiet*, and a checker that cannot stay quiet is worse than one that does not exist: **noise is what
gets a gate switched off**, and a gate that moves an exit status has no tolerance for it at all. The
count that mattered here was a zero, and a zero from an instrument with an unmeasured false-positive
rate says nothing in either direction.

**So every check owes its fixture a case it must not fire on**, chosen as the nearest thing to a true
positive that is legitimate — for a pipe inside a code span, a row with a code span and the pipe
outside it; for a wide row, a row padded with a blank trailing cell. The near-miss is the test; a
distant negative passes for free.
