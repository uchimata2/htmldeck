# L-169 — A validator reports on the file it found, not the one you meant

Found 2026-09-15 by [T-300](../../tasks/T-300-submit-htmldeck-to-anthropics-community-plugin-marketplace.md),
preparing the community marketplace submission.

`claude plugin validate . --strict` exited 0 on this repository, and its first line named what it had
read: `Validating marketplace manifest`. When `.claude-plugin/marketplace.json` sits beside
`plugin.json`, the directory form validates that manifest and nothing else. Pointed at
`.claude-plugin/plugin.json`, the same command exited 1 on a warning the directory form never raised.
The task's acceptance criterion named the directory form, so it was met while its purpose was not.

**How to apply.** When a check's pass is evidence, read the line where it names its subject, and
confirm that subject is the thing the criterion is about. For a plugin that ships a marketplace
manifest, validate `plugin.json` by path as well as the directory.
