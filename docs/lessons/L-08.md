# L-08 — Store one edge; derive the rest

Write a fact in exactly one place and compute every view of it. Facts that are computed cannot
drift from facts that are stored; two hand-maintained copies of the same relationship disagree
within a week.

**How to apply.** In the task system, the forward edge lives in the front-matter and the child
list, the "blocks" list and the index are all derived. The same rule governs prose: if another
document owns a fact, point at it (**L-13**).

**A stored copy hides more than the instance that exposes it.** Measured 2026-08-21 under
[T-208](../../tasks/T-208-shell-py-does-not-list-the-command-its-own-error-names.md). `shell.py`
kept its command list by hand in a docstring and dispatched from `if cmd == "..."` branches. The
task was raised about **one** missing command, `preflight`, named in a failure message that told
the reader to run it and listed nowhere they would look. Deriving the list from the dispatch
instead of adding the reported line found a **second** command, `tail`, that was documented nowhere
at all and that nobody had reported. **The reported instance is a sample of the drift, never its
extent** - which is the argument for deriving rather than patching, stated in the one place the
size of the gap was actually measurable.
