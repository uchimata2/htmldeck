# L-113 — A check scoped to a place stops seeing the thing when the thing gets a second home

Caught 2026-08-17 (**T-109**). The source-reference component moved: it had lived only inside
`<p class="provenance">`, and the task gave it a second home in the slide's body, where the colophon
renders the same rows. Two checks were written against the **place** rather than against the
component, and both went quiet without failing:

- `provenance_links` swept the region inside `<p class="provenance">`, so DS-105's own dead-link
  row reported **`0 of 1 examined`** on a fixture built to carry one external URL. A denominator of
  zero reads as *this deck has no links*, not as *this check no longer looks where they are*.
- DS-001's exemption was cut to the same region, so the same URL — which DS-105 admits, because an
  external URL needs the network to **follow** and not to **render** — failed as an external
  reference.

Neither is a wrong rule. Both are the right rule pointed at a place that stopped being the whole
story, and the failure mode differs by direction: the first went silently permissive, the second
loudly wrong. **The permissive one is the dangerous half**, because it prints a pass.

**How to apply.**

1. **Bind a check to the class, not to the container** — `<a class="sources-link">` wherever it
   sits, not *anchors inside the provenance mark*. Binding by class was also **tighter** here: an
   `<a>` inside a provenance mark that is not part of the component was never DS-105's to judge, and
   is not exempt from DS-001 now.
2. **When a contract widens where a part may sit, grep for every check that named the old place.**
   The contract edit and the checker edit are one change; they were two commits apart here and only
   a purpose-built fixture caught the gap.
3. **Read a denominator of zero as a question.** `0 of 0 examined` on a deck you built to carry one
   is the instrument reporting on itself. This is **L-05**'s shape at the level of one row.

The fixture is the reason this was caught at all: a throwaway deck carrying **all four** source
kinds, built precisely because three of the four already existed in shipped decks and the fourth did
not. A gate exercised only by the decks in the repository measures the decks in the repository.
