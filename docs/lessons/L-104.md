# L-104 — A page that keeps its own history has to be checked in the opposite direction

Met 2026-08-15 (**T-158**). `tools/docs/figures.py` checks a figure one way: **every numeral written in
prose must be printed by a command**, bound by making the sentence name the label the command printed.
That rule found six stale figures and has held every one since. Pointed at `CLAUDE.md`'s tier-1 bound —
the two numbers that govern what every session of this project pays — it fails in both directions at
once, and neither failure is a bug in it.

- The live sentence gives this file's own size and then the smaller document it is measured against,
  naming that document and never `CLAUDE.md`. So the first term names no label and **binds nothing**.
  Unwatched, silently.
- The record sentence beside it says what the pair *read* on an earlier date, and it names both
  documents. That **does** name a label the command prints, so it binds — and is reported stale for
  correctly stating what was true in the past. **A false alarm on a true sentence.**

*Both were quoted with their numerals until 2026-09-02, and by then the live pair had moved twice and
the record sentence had been rewritten out of the file - so the half this lesson calls a record
matched and the half it calls live did not, which inverts the distinction the lesson exists to draw.
Refreshing them restores a state that decays at the next edit to either file; the shape is what the
claim was always about (`PR-109`, and `PR-103`'s ruling for the class).*

**The page is not an account of a run, and the rule assumes it is.** A README pastes what a command
printed, so every numeral on it is current by construction. A governing document states today's figure
*and keeps the wrong ones beside it on purpose*, because the history of a number is the evidence that
it drifts. Held to a partition it was never written as, its honesty is what makes it fail.

**So the comparison inverts: every measured term must be written, rather than every written numeral
measured.** A term the page does not state fails. A numeral the page states that nothing measures is a
record, and is not judged. The same evidence, read from the other end — and it is the only direction
that can be right about a page carrying its own corrections.

**The tell is a document that quotes itself.** Before writing a checker, ask which the page is: an
account of a run, or a statement with a history. The two want opposite rules, and the wrong one does
not merely miss — it goes loud on the sentences the page was most careful about, which is how a gate
gets switched off.
