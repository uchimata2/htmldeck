# L-134 — A pipe inside a code span still splits a table cell, and Markdown drops the remainder rather than showing it

A code span protects its contents from *Markdown*. It does not protect them from the **table
parser**, which splits a row on every `|` before any inline syntax is looked at. So a command quoted
faithfully — `` `env | grep -c NAME` `` — makes a cell the header did not declare.

**What happens next is the part that costs.** GitHub-flavoured Markdown does not render the extra
cell, and it does not render an extra column. It renders exactly as many cells as the header
declares and **discards everything after them**. The row looks well-formed. The text is in the file,
`git` sees it, a search finds it, and no reader ever does.

Measured 2026-08-23 against GitHub's own renderer, on
[`../upstream/harness.md`](../upstream/harness.md) row `O-C3`. The second cell ended mid-sentence at
*and `env`*, and everything past it — the measurement, the 67 commands documented that way, the 87
hardcoded paths that replaced them, and the recommendation the observation existed to make —
rendered nowhere. Roughly four fifths of the observation. It had been in the file since 2026-08-20,
in a document written for somebody else to read. **L-101** is the neighbouring failure and this is
its sharper case: the document was wrong in the one way reading it at home could not show.

**The second half is about the gate, and it is not the obvious lesson.** This project reported the
class upstream as `O-T4`, and then **declined to build the local gate** — [T-161](../../tasks/T-161-decide-whether-to-adopt-the-wide-row-gate-now-that-upstream-ships-one.md), after measuring
307 files and zero wide rows on 2026-08-15. The offending row was written on 2026-08-20. Upstream's
gate arrived with taskmd `0.6.0` on 2026-08-23 and caught it on the first run. **The refusal was
right, and this catch is what it bought.** Declining to build a checker is only a gap if you then
stop taking the releases of the tool you deferred to.

**How to apply.**

1. **Escape a pipe inside a table cell, code span or not** — write `\|`. It changes the source and
   not one character of what the reader sees, so the quoted command stays exact.
2. **Verify a rendering defect by rendering.** Reading the source cannot show you this one: the
   source is the only place the text still exists. A renderer is the instrument, and the cheap one
   is a `POST /markdown` against the same engine the reader will use.
3. **When you decline to build a gate because your tree measures clean, date the measurement.** A
   clean sweep is a fact about a day, not a property of the project. The refusal stays sound; the
   number underneath it expires.
4. **A document written to be sent is the worst place for this**, because the audience that would
   have noticed is the one that never received it. Check the rows of an outgoing register before it
   goes, and check them again if it gains a row afterwards — `O-C3` was added six days after the
   document's disposition was settled.
