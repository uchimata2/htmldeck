# L-76 — A simulation of the target surface is a different surface, and it will say so only once

Caught 2026-08-13 (**T-116**). `contents_bound.py` measures the printed contents page by lifting the
deck's own `@media print` rules onto screen through the CSSOM — the rules themselves, not a copy, and
that care is real. It is still not print. The same deck, the same day, measured both ways:

| | box height | rows 2→3 gap | verdict |
| :--- | ---: | ---: | :--- |
| screen, with the print rules lifted onto it | 175.7 du | +26.0 du | clean |
| the printed PDF | 200.2 pt = 267 du | −49.2 pt | rows print through each other |

The tracks agreed. The **item** did not: on screen a grid item's automatic minimum size is zeroed
because `overflow:hidden` says to, so the box takes its track and clips; Chrome's paged layout gives
it its own content height instead. A 267 du card in a 201 du pitch overhangs by a third of a row, so
cards printed through each other and through the page footnote — in the first adopting project's
presented deck **and in this repository's own reference deck**, which is the same 13 entries. Every
gate was green for both, and the tool aimed at that page reported the layout clean.

The trap is that the simulation is not wrong most of the time. It was right about the tracks, right
about the columns, right about the compression, and right about the bound. It was wrong about one
property, and one is enough.

**How to apply.**

1. **Take the first reading on the real surface, even if every later one is a proxy.** The proxy's
   job is to be cheap on the second run, not to establish that it agrees.
2. **Say in the tool what surface it measures and what that surface cannot show.** A closing line
   that the numbers "do not discharge printing and looking" was already there, was correct, and was
   read as a formality. Name the fault it missed, so the sentence carries evidence instead of
   modesty.
3. **When a fixture and an instrument are both suspect, fix the instrument first.** The obvious
   diagnosis here was the fixture's entry height, and it was a real second cause — but a taller
   fixture measured on screen still came back clean. Verified by running exactly that, rather than
   assumed (**L-05**).
4. **A defect an adopter reports on their own deck is worth printing your own against.** The
   reference deck had the same fault at the same count and nobody had printed it since the change
   that took it to 13 entries. Same shape as **T-083**.
