# L-140 — A classifier that silently reclassifies is worse than one that crashes; `rstrip` takes a character set, not a suffix

`str.rstrip("!important")` reads as *remove the trailing `!important`*. It removes any run of the
characters `!`, `i`, `m`, `p`, `o`, `r`, `t`, `a`, `n` from the right. `"pop"` is three characters
all drawn from that set, so it reduces to the empty string. `"none"` reduces to `"e"`. The same
holds for `lstrip` and `strip`, and for `removeprefix`/`removesuffix` only in the sense that those
are what the author meant.

Found 2026-08-29 in `tools/deck/density.py` while closing
[T-243](../../tasks/T-243-five-checks-bound-on-a-name-rather-than-on-structure.md). The test read

```python
if all(v.strip().split()[0].rstrip("!important").strip() in ("none", "") for v in live if v.strip()):
    continue                       # this rule switches motion off; it starts nothing
```

so a rule declaring `animation:pop 1s` was classified as one **switching motion off**. It left the
motion set entirely, and its `--motion-kind` declaration left with it — silently, with a correct
count printed beside it. Nothing in this tree animates a name that spells out of those nine letters,
which is why it had never fired and why no test caught it.

**The damage is the direction, not the API.** A wrong `rstrip` that produced a crash would have been
found the first time it ran. This one produced a *plausible other category*, and the row that
reports the category still printed a denominator — `0 undeclared of 13` rather than `of 14` — which
reads exactly like a pass.

**How to apply.**

1. **Use the operation you mean.** `removesuffix` for a suffix; a regex anchored with `$`; slicing
   with an explicit `endswith` guard. `rstrip` is for whitespace and for genuine character classes.
2. **Suspect every string call whose argument is a word.** `strip`, `rstrip`, `lstrip` taking a
   multi-character literal is the tell, and it is one grep across a repository.
3. **A classifier's fixture must include a member of every class it can silently move something
   into.** The self-test here had `animation:none` and `animation:rise` and passed for years; it
   needed one animation whose *name* could be eaten, which is a fixture nobody writes without
   knowing the defect. Adding it is cheap once the class is named.
4. **Prefer failing loudly to reclassifying.** Where a predicate cannot tell which class a value is
   in, say so and let a row read *undecided*; this project already has a third state for that, and
   [L-36](L-36.md) is why the denominator travels with the verdict.
5. **A tool the next fix depends on is read before it is trusted.** This was found because DS-239's
   vocabulary was being re-derived from the same function; a re-binding that reads a lying function
   inherits the lie, which is [L-125](L-125.md) one layer down.
