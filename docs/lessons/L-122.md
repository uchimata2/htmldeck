# L-122 — A frozen clock makes a finished thing and an unstarted thing read alike

An instrument that reports a value which never changes is usually caught quickly: the number is
obviously wrong, or obviously constant. The dangerous case is when the frozen value is also a
**legitimate** value — because then it is not a reading you distrust, it is a reading you act on.

Measured 2026-08-19. Headless Chrome produces no frames, so no CSS animation's clock ever starts:
every animation on the page reports `currentTime: 0`. That includes both of these, and they are
opposites:

- an animation that has **not begun** — the slide arriving is about to fade in;
- an animation that **finished long ago** — the slide leaving faded in a minute of wall-clock ago,
  and carries `fill: both`, so it is still in `getAnimations()` and still holding its end state.

A tool that seeks every animation to a moment on a shared clock treats those the same and rewinds
the second one to its start. **The resulting screenshot is of a page in a state that never
exists** — and it is a perfectly plausible-looking screenshot, which is the whole problem. The one
this was found in showed a nearly blank slide: the content that had been on screen for a minute was
seeked back to opacity 0.

**What made it visible was looking at the output, not reading the code.** The frame was 38 KB where
its neighbours were 120; a size that small is a page with almost nothing on it, and the tool
reported success either way.

**How to apply.**

1. **Never infer state from a value a frozen instrument reports.** If the clock does not run, then
   `currentTime`, `elapsed`, `progress` and every derived flag are the same value for every subject,
   and comparing them is comparing nothing.
2. **Take the set before the event and difference it.** Identity is the thing the frozen reading
   cannot fake: what appeared as a result of the action is the action's, and what was already there
   is not. This works when no timestamp does.
3. **Put what was already there at its END, not at the start of your clock.** Its animation
   completed; that is the only state consistent with it having been on screen.
4. **Size the output, and be suspicious of an outlier.** A capture much smaller than its
   neighbours is a picture of less; that is a cheap check on an instrument nothing else audits.

The general shape: **a stopped clock does not report "unknown", it reports a plausible number**, and
every consumer downstream treats it as measured. Related: **L-110** — the instrument that fails
silently — and **L-36**, since a value that is the same for everything is a check that has no
denominator.
