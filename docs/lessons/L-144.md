# L-144 — When a rule has never fired, the number that catches a bad guard is the population the guard would exempt

[L-143](L-143.md) says to write down what a check currently counts before narrowing it, because a
guard that swallows everything arrives looking like a clean run. That works when the rule has a
prior count. **Some rules have never fired at all**, and for those the prior count is zero before
the change and zero after it — the instrument L-143 relies on reads the same either way.

Found 2026-08-29 in [T-270](../../tasks/T-270-two-rules-whose-escape-hatch-teaches-the-wrong-habit.md).
An adopter report proposed narrowing DS-100, *no rhetorical questions*, to exempt a question the
slide answers, and offered the condition as already checkable: *a `?` followed, within the slide, by
a declarative bottom line*. The owner ruled to take it. DS-100 has never fired on any deck in this
repository — three decks, zero question marks in copy — so there was no prior count to protect it.

**The guard was measured instead of the rule.** How many slides satisfy *has a declarative bottom
line*? **Thirty-eight of thirty-eight.** The component contract puts exactly one `.bottom-line` on
every slide and DS-202 requires it to be one factual sentence, so the condition is true by
construction and the narrowing is an off switch wearing a plausible sentence. Two documents this
project already owns said so, and neither is the check.

**Why it reads as checkable when it is not.** *A question the slide answers* is a real distinction
and the condition is a real property; what is missing is that the property is **not discriminating**.
A condition is only a test if something fails it, and nothing about the sentence tells you whether
anything does. That is the same shape as [L-142](L-142.md) one step earlier: from inside the
proposal, a guard that exempts the right case and a guard that exempts every case read identically.

**How to apply.**

1. **Measure the guard's population before writing the guard.** Not *does it admit the case I was
   given* — one case cannot fail a condition — but *how many of the things the rule looks at does it
   admit*. A guard admitting all of them is an off switch whatever it is called.
2. **A rule that has never fired cannot be protected by its own prior count.** Reach for the
   population instead; it is available even when the firing rate is zero, and it is the cheaper
   measurement in any case.
3. **Look for the condition in the project's other contracts before trusting it.** Here, *has a
   declarative bottom line* was already guaranteed by a component contract and a second rule. A
   guard whose truth another document mandates is not a guard.
4. **A ruled remedy is still a hypothesis.** The measurement outranks the ruling, and refusing one
   is not a challenge to the authority that gave it — it is what the authority asked for when it
   said the remedy is a proposal. Record the measurement and put the question back with a
   recommendation, rather than implementing a sentence you have shown to be empty.
