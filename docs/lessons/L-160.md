# L-160 — A snapshot document dates its values and forgets to date its membership, so a subject added after the run reads as a subject never examined

Found 2026-09-02 in [T-249](../../tasks/T-249-the-two-prior-audits-registers.md), closing `PR-90`.
[`RULESET-AUDIT.md`](../RULESET-AUDIT.md) opened *Every rule in `DESIGN-SYSTEM.md` tested against one
question* and held **165** rows against a ruleset of **177**. Its own caveat said *this is a dated
snapshot and it does not update itself* — and then covered one direction only: a rule **amended**
after the run has a verdict about the wording it used to carry. A rule **added** after the run has no
row at all, and nothing in the document said so. Its stated purpose is *read when someone asks
whether a rule was ever examined*, so for twelve rules that question returned a silence
indistinguishable from a failed search.

- **The membership is a value too, and it is the one a caveat forgets.** A snapshot's warning reaches
  naturally for what it copied — the columns, the counts, the verdicts — because those are what a
  reader can watch go stale. It does not reach for the row that is not there, because no reader can
  see that one at all.
- **Measure the shortfall before believing it.** All twelve rules with no row were added *after* the
  run — `git log -1 -S` dates them 2026-08-18 to 2026-08-21 against a 2026-08-17 run — so the audit
  examined its whole subject and the defect was an undated denominator, not twelve skipped rules.
  Read the other way it commissions a second audit that nothing needs.
- **The excluded list is not the fix.** Writing *`DS-233` to `DS-244` have no row* is correct today
  and wrong on the next rule added: the same decay one turn later, which is [L-152](L-152.md). Name
  what derives it instead — `python tools/deck/ruleset.py`'s ids against section 5's ID column.
- **So a dated document dates both halves**: *every X as of DATE* in the sentence that claims
  coverage, and one line naming what answers *which X have no row now*. The first is a fact with a
  date on it; the second is the only thing that stays true without an editor.
