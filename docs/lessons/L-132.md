# L-132 — Make the forbidden thing its own marker, and make it the only failure

When an artifact must be prevented from travelling, the reflex is to add a flag that says *do not
ship this*. The flag is a second object, and a second object can be removed on its own. Then the
artifact still carries the thing you were guarding against, and now it passes.

**The marker should be the thing itself.** Measured 2026-08-22 under
[T-213](../../tasks/T-213-build-the-presenter-build-and-the-marker-that-keeps-it-unshippable.md). A
presenter build carries speaker notes, and DS-088 forbids notes in a shipped deck. Its checker is
one string: `"speaker-note" not in h`. So carrying the notes in `class="speaker-note"` makes the
build unshippable **because it contains notes** — there is nothing to strip that does not also strip
the notes. A `data-presenter` attribute would have been the reflex answer, and a build that lost it
would have passed while still leaking every note in it.

The test: **ask what a careless edit removes.** If it can remove the marker and leave the hazard,
the marker is decoration. If removing the marker means removing the hazard, the property is
structural and nobody has to remember it.

**The second half is legibility, and it is not a separate lesson.** The same build first failed
three rules, not one: the injected chrome used raw lengths and a `vh` unit, so DS-010 and DS-033 went
red beside DS-088. Every figure was correct and the safety property held — but a maintainer meeting
three failures cannot see which one is the design, and **the shortest path to a quiet gate is
deleting the notes.** Rewriting the chrome on the host's own tokens brought it to exactly one
failure, which is now an assertable invariant rather than a hope: *the presenter build fails DS-088
and nothing else.*

A deliberate failure has to be **the only** failure, or it stops reading as deliberate.

**How to apply.**

1. **Look for a check that already fails on the hazard before writing one that fails on a flag.**
   Here the rule, its checker and its string already existed; the work was choosing a class name.
   Nothing was added to the ruleset.
2. **Count what has to stay in sync.** A flag plus a hazard is two things and one invariant nobody
   enforces. The hazard alone is one thing and no invariant.
3. **Anything you inject into someone else's artifact must obey that artifact's rules.** An overlay
   that breaks the host's conventions adds failures that are about the overlay, and they sit in the
   same list as the ones that are about the design.
4. **Assert the failure set, not the failure.** *It fails* is satisfied by failing for the wrong
   reason. *It fails on exactly this rule* is the statement worth recording, and it is the one that
   catches an overlay quietly acquiring a second defect.
5. **Structural beats procedural everywhere it is available.** The generated file is also named
   `<slug>-presenter.html` and is `.gitignore`d, because `check_all.py` fails any tracked `.html` it
   has no entry for — so committing one goes red rather than shipping.

Related: **L-131** for a correct measurement of the wrong subject, which is this failure's mirror —
there the instrument was right and the target wrong; here the verdict is right and the reason must
be unambiguous. **L-125** for binding on structure rather than vocabulary.
