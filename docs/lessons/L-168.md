# L-168 — A cut stays cut only where a gate re-measures it

Found 2026-09-14 by [T-294](../../tasks/T-294-grade-the-second-context-economy-runs-bands-after-its-remedies-land.md),
grading a context-economy audit twelve days after its remedies landed.

Every cut that a check re-reads held. `CLAUDE.md` stayed at the size `figures.py` holds it to, and
the two quiet green outputs a self-test asserts stayed one line. Every cut that nothing re-reads grew
back. The memory index lost 219 bytes and then gained 531, ending above where the audit found it.
The skill catalogue and the start context grew with no file here changing.

**How to apply.** When a remedy for a per-turn cost closes, name the check that will see the cost
come back. Where there is none, say so in the record, name who owns the surface, and do not report
the saving as kept.
