# Marnfield depot — fleet and cost model

**Marnfield is an illustrative parcel network. It does not exist.** Costs are illustrative and
derive from the assumptions stated with them.

## The fleet as it stands

| | |
| :--- | ---: |
| Vans in service | 34 |
| Mean round utilisation, off-peak | 71% |
| Mean round utilisation, peak | 88% |

Utilisation is measured as parcels loaded against the van's rated capacity at departure. A round
that leaves 12% empty in the busiest month is not a round short of space.

## Option A — nine more vans

| | |
| :--- | ---: |
| Vans | 9 |
| Capital | $522k |
| Drivers and running cost, annual | $468k |
| First benefit | 5 months — procurement, livery and driver recruitment |

Reaches only the parcels that were **sorted and not loaded**, which is 16% of peak misses. A van
cannot carry a parcel the sorter has not released.

## Option B — move the window

| | |
| :--- | ---: |
| Linehaul slot premium, annual | $140k |
| Twilight loading crew, six people, annual | $170k |
| Crew shift, five nights a week through peak | 22:00 to 02:30 |
| Total, annual | $310k |
| Capital | none |
| First benefit | 6 weeks — a schedule change and a shift pattern |

Two changes together: the second trunk arrives at **21:50** instead of 23:40, and a second outbound
cut-off runs at **02:30**.

The earlier slot moves the trunk **110 minutes**. Sorting still takes 2h 19m, so it finishes at
**00:09** — inside the existing 01:00 cut-off, with 51 minutes to spare. The second cut-off at 02:30
is what covers the nights the slot is missed — the remaining **5%**.

Projected peak miss rate after the change: **2.4%**. The projection holds the sort rate, the volume
and the district sequence constant, and assumes the earlier slot is met on 95% of nights — the
carrier's own contractual floor.

## What is held back

**$120k of the $310k is held to the January review.** If the peak miss rate has not fallen below
**4%**, the fleet case is reopened with a season of evidence behind it rather than ahead of it.
