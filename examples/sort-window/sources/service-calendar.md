# Marnfield depot — service calendar and thresholds

**Marnfield is an illustrative parcel network. It does not exist.**

## Dates

| | |
| :--- | :--- |
| Peak season | 18 November to 23 December |
| Network contract review | 14 November |
| Linehaul slot request notice | 8 weeks before the slot changes |
| Latest decision date | 19 September |
| January review | the first working week of January |

The 19 September date is 8 weeks before the contract review and is not a preference: a slot
requested later than that cannot be in place for the first week of peak, which is the week the miss
rate has climbed in for three consecutive years.

## Thresholds

| | |
| :--- | ---: |
| Next-day service level, contractual | 96% |
| Equivalent miss rate | 4% |
| Peak miss rate, this year | 12.4% |
| January review trigger | peak miss rate at or above 4% |

## The shift pattern

Sorting runs 20:00 to 01:00 on a single line. The proposed second cut-off at 02:30 extends the
outbound window by 90 minutes and needs a six-person crew; it does not extend the sort shift, which
is why it costs a crew and not a line.
